
# TASK-03: Semantic HTML5 & Accessible Component Architecture

## Overview
A responsive enterprise dashboard built using semantic HTML5,
CSS, and vanilla JavaScript.

## Features
- Semantic HTML5 page structure
- Responsive sidebar and header
- Dashboard statistics and accessible data tables
- Multiple pages: Dashboard, Users, and Reports
- Accessible modal dialog and form validation
- Keyboard navigation and visible focus indicators
- WCAG 2.1 accessibility considerations

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
1. Clone or download this repository.
2. Open the project in VS Code.
3. Launch index.html using the Live Server extension.
4. Test the Dashboard, Users, Reports, and Add User dialog.

## Validation
Validate the HTML files using https://validator.w3.org/

## Notes
The dashboard uses sample data and does not connect to a database.
New users added through the form are displayed in the current page
only and are not persisted after a refresh.
